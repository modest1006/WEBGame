# ことばのわ

3歳ごろから、文字が読めなくても絵をタップして遊べる「言葉のつながり」ゲームです。罰・制限時間・ゲームオーバーはありません。

## 遊び方

- **さんぽ**: 真ん中の絵につながる周りの絵をタップするか、真ん中へ運んで、自由に言葉を渡り歩きます。🎲はランダムジャンプです。
- **めざせ**: 画面上の目標まで、つながる絵を順番に選びます。絵を真ん中へ投げても進めます。15秒迷うと次の絵がやさしく光ります。
- **だれかな**: 周りの絵とのつながりから、下の3つの絵のうち「だれか」を当てます。選択肢はタップするか、❓へ運んで答えます。違う絵を選んでも、暗くなるだけで何度でも続けられます。

右上の🔊で効果音をミュートできます。左上の⌂またはPCのEscキーでタイトルへ戻ります。タッチとマウスの両方に対応し、`index.html` の `file://` 直開きでも遊べます。

周りの絵やクイズの選択肢は、少し大きく動かすと持ち上がります。回るリングと流れる点線を目印に真ん中へ運べます。指が22px未満しか動かなかった場合は、長く触れていても通常のタップとして扱います。

## デバッグ

URLに `?seed=123` を付けると乱数を固定し、`?debug=1` を付けると状態オーバーレイを表示します。

`window.__game`:

- `getState()` — 現在のモード、中央語、隣接語、目標、クイズ、スコアなどのスナップショット
- `dump()` — 画面状態のASCII表示
- `step(ms)` — ゲーム内タイマーと描画を指定時間進める
- `jumpTo(id)` — 指定語を中央へ設定
- `setMode(mode)` — `walk` / `quest` / `quiz` へ直接切替
- `tapWord(id)` — 表示中の隣接語または選択肢をタップ
- `dragWord(id, toX, toY, {release, vx, vy})` — 実際のpointerイベント経路で、語を画面座標へドラッグ／リリース（`vx`, `vy`はフリック検証用px/s）
- `iconDataURL(name)` — プロシージャルアイコンを256px PNG dataURLで取得（白バイは`shirobai`）
- `validateGraph()` — グラフの対称性・連結性・クイズ出題可能語数を検証
- `findPath(from, to)` — BFSによる最短経路

`window.__renderOnce(dt)` は、非表示タブでもエフェクトを1フレーム手動描画します。
